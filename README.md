This is my take on an skinnable MP3 player for the DS/DSi. It is a port of Webamp which is a reimplementation of Winamp. There are 100k Winamp skins available. Hopefully this keeps you busy for a while.

https://skins.webamp.org

I really tried to think of how I would want to use this myself. I've been walking around with it in my pocket ensuring that it met my needs. I'm being silly optimistic here, but with everyone back on the MP3 player train it felt like might stand a chance.

I keep picking projects that should probably be DSi exclusive. Instead I hammer on them until they work on the DS as well. This uses about 50% of the DSi CPU and closer to 90% on the DS. It will play MP3s up to 320 KBPS.

The skin support should load any .wsz format skin. If you download one that happens to look wonky please try another.

Some features:

Full skin support

Directory browsing

Playlist support - .m3u loading and creation

EQ support with multiple presets

Locking controls for in pocket playback

Multiple visualizations that can be toggled by touchscreen

Directions:

Drop mp3s in /music

Winamp .wsz skins in /skins

Press select to change tabs

Press start+select to lock the controls

Hopefully this tickles some nostalgia bones.

While this is Claude Slop generated, it has gone through a stupid number of revisions before I am happy. I try not to put out anything that I wouldn't want to use myself. Feedback and suggestions are welcome.
